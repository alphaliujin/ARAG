ARAG 业务流程v0.2.0

敏感信息识别系统 · Sensitive Information Detection System — 基于 RAG 的文档涉密信息检测

先建库, 后检测：把按密级分类的敏感文档预处理、切片、向量化, 建立敏感信息 RAG 库; 再对用户上传的待检文档 / 文本进行层级比对, 输出各密级相似度, 识别其中是否含有敏感 / 涉密内容。

业务泳道 知识库构建 文档检测 DocScan 文本扫描
密级 0Public 公开 1Restricted 受限 2Confidential 机密

核心数据流总览

源文档 DOC/<密级>/→ ① 预处理 X2MD 转换·清洗·父子块切片→ 切片 MD/<密级>/→ ② 入库 MD2RAG bge-m3 嵌入 → ChromaDB 分集合→ RAG 库 vector_db/ 三密级 × 父子块→ ③ 跨密级去重→ ④ 待检文档 / 文本 层级比对→ 密级相似度结果 /ARAG-end/

流程一 · 知识库构建

把敏感资料建成按密级分类的 RAG 库 后台任务 · 进度可查 · 可取消
1

源文档准备

  • 文档按密级放入 DOC/ 目录
  • 支持扫描源目录查看待处理文件
0Public 公开 1Restricted 受限 2Confidential 机密
GET /api/v1/scan-source-dir
→
2

预处理X2MD

  • 多格式 → Markdown：PDF / DOCX / XLSX / PPTX / HTML / 图片 / TXT
  • 可选：OCR (Tesseract) · 表格提取 · LLM 摘要 (qwen3:14b)
  • 切片参数 chunk_size / chunk_overlap 可调
转换→清洗→父子块切片
POST /api/v1/tasks/preprocess
输出 MD/<密级>/*.md + parents/children.json
→
3

入库MD2RAG

  • Ollama bge-m3 嵌入（1024 维）
  • 写入 ChromaDB，按密级分集合
  • md2rag_{密级}_{parent|child} 共 6 个集合
  • 增量入库 · 支持全量重建
POST /api/v1/tasks/ingest
输出 vector_db/ 持久化向量库
→
4

跨密级去重

  • 跨密级比对子块相似度
  • 高密级库中与低密级重复的块 → 删除
  • 结果分档报告 · 可人工审查后应用
POST /api/v1/tasks/dedup · /dedup/apply

流程二 · 文档检测DocScan

上传待检文档，层级比对判定涉密相似度 上传 → 预处理 → 嵌入 → 层级比对
1

上传待检文档

  • 支持 PDF / DOCX / XLSX / PPTX / HTML / MD / TXT
  • 大小上限 50MB
  • 仅保存至 DocScan/，不自动处理
  • 防路径穿越 · 重名自动加后缀
POST /api/v1/scan/file
→
2

预处理

  • X2MD 转换 + 父子块切片
  • 参数与入库侧一致、可单独调整
POST /api/v1/docscan/preprocess
输出 *.parents.json / *.children.json
→
3

嵌入

  • 读取切片 → 批量嵌入
  • 向量写入 JSON 带标记
  • 后台任务 · 进度可查 · 可取消
POST /api/v1/docscan/embed
→
4

层级比对核心

  • 摘要 → 父块 → 子块 逐级与三密级库比对
  • 某级相似度 ≥ 80% → 跳过下级
  • 多信号融合打分
摘要向量→父块向量→子块向量
POST /api/v1/docscan/compare
输出 /ARAG-end/public:0.85,restricted:0.72,…

支撑层 · 公共能力

🗂 后台任务管理

preprocess / ingest / dedup / docscan_embed 异步执行; 进度轮询、可取消、同类任务防重。services/task_manager.py

⚙️ 运行时配置

相似度阈值、切片参数、上传限制、嵌入模型等, 前端「设置」页动态调整, 持久化于 runtime_settings.json。

🔐 安全防护

API Key 认证中间件（Key 为空自动跳过）; CORS 白名单; 路径穿越防护; 上传扩展名白名单。middleware/auth.py

🧠 向量基础设施

Ollama bge-m3（1024 维嵌入）; ChromaDB 持久化于 vector_db/; 可选 bge-reranker-v2-m3 重排序。services/vector_db.py

📄 文档转换工具

X2MD 多格式转 Markdown; MD2RAG 切片向量化入库; 可选 Tesseract OCR / qwen3:14b 摘要。

🚀 部署形态

单进程 uvicorn :8000 同源服务前端 + API, 无需 nginx / Node; start.sh / stop.sh 一键启停。
